# GRIDS - Graduates Rising in Data Science

Official website for GRIDS (Graduates Rising in Data Science), the first graduate student organization within the USC Viterbi School of Engineering's Lord Department of Computer Science.

## About

This is the official GitHub Pages website for GRIDS. The website showcases our mission, current projects, and upcoming events.

## Website Structure

- `index.html` - Main website page
- `styles.css` - Website styling
- `script.js` - Interactive features and smooth scrolling

## Deployment

This website is automatically deployed via GitHub Pages. Simply push changes to the `main` branch and the website will update automatically at `https://gridsusc.github.io`.
